    viz_tree ¶

    VizTree ¶

    VizTree is used to store the tree and visualise it in the application. It wraps a linked tree of BaseNode instances and provides the operations the visualization app needs: node/edge collection, prediction, collapsing/expanding subtrees, pruning, and serialization. It also saves the training data.

    Attributes:

    Name Type Description
    root_node BaseNode

    Root node of the linked tree.
    nodes List[BaseNode]

    Flat list of all nodes in the tree.
    edges List[Tuple[BaseNode, BaseNode]]

    List of (parent, child) node pairs for every edge in the tree.
    X_train ndarray

    Training feature matrix used to fit the tree.
    y_train ndarray

    Training target values used to fit the tree.
    y_hat ndarray

    Predictions of the tree on X_train.
    tree_id str

    Identifier for this tree, defaults to a unique ID.
