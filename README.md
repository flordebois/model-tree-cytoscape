# model-tree-cytoscape (cytoscape branch)

**Note:** This branch contains the legacy, single-page version of the Cytoscape visualization app. For the latest multi-page application, please switch to the `main` branch.

## Overview

This repository holds the legacy codebase for interactive model-tree visualizations using Cytoscape. It provides a lightweight, single-page web interface to inspect generated tree structures. It is preserved for backward compatibility and baseline reference. Active development and newer multi-page features are maintained on `main`.

## Quick Start

1. **Clone the branch:**
   ```bash
   git clone -b cytoscape https://github.com/your-username/model-tree-cytoscape.git
   cd model-tree-cytoscape
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   python app.py
   ```
   Open `http://127.0.0.1:8050/` in your browser to view the visualization interface.
